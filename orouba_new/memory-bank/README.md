# Memory Bank

Start here:
- `projectbrief.md` - what the project is trying to achieve.
- `activeContext.md` - current state as of the latest inspection.
- `progress.md` - what works, what does not, and next priority order.
- `known-issues.md` - build, lint, hydration, 404, backend, and text risks.
- `routes.md` - route inventory and redirect coverage.
- `data-and-media.md` - database, legacy API, and R2 media status.
- `systemPatterns.md` - architecture patterns in the current code.
- `techContext.md` - stack, commands, environment notes, validation status.
- `productContext.md` - user journeys and UX expectations.
- `qa-checklist.md` - practical verification checklist.
- `route-sweep.latest.json` - latest local route sweep result.
